# Brand Guidelines

Always use the Digital Ghuru brand colors for primary actions and highlights.
**NEVER** use generic colors like plain blue for primary calls to action unless explicitly requested.

## Primary Button Color
The primary brand color is a gradient from Amber to Orange.
Always use this gradient for primary buttons, submit buttons, and major calls to action:
`bg-gradient-to-r from-[#FFB800] to-[#FF5C00] text-white`

Alternative (if using Tailwind named colors):
`bg-gradient-to-r from-amber-400 to-brand-orange` (or `orange-500`)

When creating custom buttons that cannot use the `<Button>` component directly, copy these styles.
